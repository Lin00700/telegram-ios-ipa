# 视觉方向：水墨暖色调，原生聊天结构

参考 `/home/ubuntu/upload/IMG_7653.PNG` 中 CF 助手完整版的视觉特征，而不是复制其页面内容：

- 页面基底：柔和暖象牙白 `#F6F3E9`；卡片略浅 `#FBF9F1`，用低对比米灰描边 `#E4DFD2`。
- 主文字：深墨色 `#211F1B`；次级文字 `#746F66`。
- 强调色：砖红 `#AD4039`，仅用于图标、选中态、状态点与主要操作，避免整屏高饱和色。
- 形状：18–24 pt 圆角、轻边框、少量柔和阴影；按钮采用胶囊/圆角矩形；信息分组采用两列或清晰列表。
- 导航：底部导航可采用浅色半透明胶囊、明确选中态和大尺寸触控目标，但不删除或重排 Telegram 关键消息入口。

## 在消息应用中的适配

截图是管理控制台，并非聊天界面，因此不照搬“域名/Workers/DNS”卡片。聊天列表与聊天记录仍保持熟悉的原生层级、消息气泡、附件、搜索、语音/视频、通知和可访问性；水墨暖纸色、砖红强调和低对比边线贯穿共享导航、列表、对话气泡、输入面板与弹层。发送中的 AI 文案应清楚标识为 AI 生成，便于用户识别。

## 中文界面与聊天翻译

新增设置与消息操作提供简体中文（`zh-Hans`）文案。自动翻译时，原文完整保留，译文作为标注清楚的次级文本显示在原文下方；不能用“切换到原文”的按钮替代双语同时显示。译文采用次级墨灰文字和轻分隔，翻译开关用简洁状态点/圆角控件表达，不增加高饱和色块。目标语言默认简体中文，但每个会话的翻译仍由用户单独开启。

## 应用身份

`assets/unofficial-chat-icon.png` 是新绘制的抽象对话气泡标志，不包含 Telegram 的标准纸飞机或名称。默认显示名称为 `Unofficial Chat`；用户可在构建参数中改名，但仍须清楚保持“非官方”身份。
